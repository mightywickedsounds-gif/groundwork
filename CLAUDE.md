# Flowtown (repo: groundwork)

A browser traffic game, hosted on GitHub Pages from `main` (root): https://mightywickedsounds-gif.github.io/groundwork/. This is a standalone project. The repo is public: never mention or link the owner's other projects, and keep personal details out of files and commit messages.

- No build step. three.js 0.160 from jsDelivr via the import map in `index.html` (CSP meta there; add any new host). The import map also pins our own modules to `?v=N` (and `game.js?v=N` in the script tag): bump N in both places on every change that reaches `main`, or phones mix cached old and new files.
- `net.js` (no three, runs in Node): `Net` = nodes/edges (quadratic curves `cx,cz`, `oneway` 0/1/-1, `ring` id, `kind`), `probe`/`realize`/`planRoad`/`addRoad` (plan first without changing anything; every crossing becomes a junction or the road is refused with a `.reason`; `crossesOthers` + `restore(snapshot)` undo anything that would leave a crossing without a junction; snap radius passed in from the zoom), `removeEdge`, `toggleSignal`, `cycleOneWay`, `makeRoundabout`/`roundaboutOnRoad`/`removeRoundabout` (radius from `ringFit` toward `ringWant(spokes)` = room for every spoke's width, up to 30, min 8; `ringLanes` = 2 ring lanes when a wide road comes in, ring edges carry `nl`; on a ring approach every lane serves every movement; stored per ring node as `rc` [x,z,R]; close spokes share an entrance; one-way arcs going toward decreasing angle). Lanes: each edge has `nl` lanes each way (1-3) and `tl` turn lanes (`LANE_STEPS`, `cycleLanes` = Lanes tool over `roadChain` through bends, adds lights where 3+ wide legs meet); width from `halfW(e)`, lane offset `laneOff(e, i)` (i = nl is the turn lane, in the middle for two-way). `rebuild()` makes lanes (right-hand traffic, right normal is (-dz, dx), x east, z south; key `<edge>f|b` = kerb lane, `f1`.. inner, `fp` turn lane; `li`, `pk`, `off`, `Fa/Fb` for `mapS`, `chg` = lanes it may move to, `mv` arrow bits 1 straight 2 right 4 left) trimmed by `trimOf(node)` (grows with width), turn lanes where a left turn exists (`e.pk` = lengths at ends a/b), and connectors per node from lane assignment (kerb lane right, inner lane left, weights straight 3) via `connect()` with `conflicts`; keeps cars and their routes when lanes survive. `step(dt)`: lane changes (`chgTo` = next route lane beside, `gapOK`, wait near the end, cars behind yield via `mq`, sideways drift `lat`), IDM following, junction permission `canEnter` (room on the out-lane, conflicting connectors `busy`, signal state, ring priority + ring fill cap `ringOcc`, first-come-first-served `arrT`), give up after `GIVE_UP` s; a granted car that can't move lets go after 2 s. Drawing pose: `posAt` reaches back onto `car.prev` (lane before) or `car.side` (lane beside, after a lane change) so the body sits between front and rear wheels; `lat`/`latT` = sideways offset (lane change drift, pulling out from / in to the kerb), `sig` = blinker 0/1 left/2 right. Routing = Dijkstra on lanes with `cost` (live lane speed `spd`) plus lane moves `chgCost`; trips start/end in kerb lanes. Saves: edge arrays end with `nl, tl`. `MAP_EDGE` = no roads beyond 1600 m (hills). Cars: `temper` speed factor from the colour roll, `TYPES[].acc` slower trucks/buses, `stopAt(n, e)` = stop sign (slow to `STOP_V` at the line; avenues/wide roads don't stop for smaller streets).
- `city.js` (no three): `BLOCK` grid, districts of `CHUNK` blocks unlocked centre-out (`order`, `nextDistrict`, `unlock`; district-edge avenues = arterials built as 2 lanes + turn lane with lights where 3+ avenue legs meet), `fillBlock` per block side: `core` (town centre within `CORE_R`), `corridor` (avenue frontage: shop strips / big stores / offices / garden apartments with parking lots), `home` (houses with `lw`/`ld` lot size for fences); `SETBACK`/`SETBACK_AV`; `TRIPS` per resident; parks/parking/yards (a lot may have `rot` and `bid`: `frontLot(b)` puts one between a business/apartment and its street, `ensureLots()` for old saves, drawn in its own frame), `sync()` cuts buildings/lots back from new roads (`cutsFor`/`cutBack`, `C.cutBack` count) or demolishes them, and attaches buildings to streets; `regrow(dt)` (game + grow test) adds buildings along any street inside unlocked districts facing it (`b.rot`: local x axis = (cos, sin); drawn with rotation.y = -rot; saved as building field 15), committing every 12 s (`C.ver++`); `hitsRoad` pads wide roads by `halfW - 3.5`, `demand`/`release` trips by `rushCurve(hour)`, `wild()` woods on unbuilt land (looks only). Never add random draws to existing generation (it would move things in saved cities); hash/seed only.
- `sky.js`: `makeSky(renderer)` sky dome shader (time of day, sunset, clouds, stars, moon), `horizon()` = fog colour, `env()` re-renders the environment map (PMREM) from the same sky when the sun moves. `game.js` `lighting(hour)` drives it (sun east -> south at noon -> west), `hillH` = hills beyond `HILL0` (ground mesh displaced; camera kept above them).
- `draw.js`: `buildRoads` (`piece` = one stretch of road; two roads joined end to end are drawn as one smooth `elbow` (control = where the end headings meet), not a junction; `piece(..., ends)` sets exact end normals so pieces meet without slivers; asphalt strips, junction fans with curb returns `corner` (straight kerb when legs are ~opposite; sidewalk outer edge = kerb offset), ring markings as full circles, raised sidewalks, markings (`seg`, `hatch` median, per-lane `turnArrow` from `mv`), stop/give-way lines, zebras, islands, street-light spots), `buildCity` (instanced buildings with the window shader `buildingMaterial`: photo walls by `aWall` 0 stucco / 1 brick / 2 limestone from `FACADE`, hash inputs quantised; `roofMaterial` shingles in world space; parapets, roof units, awnings, garage/front doors, chimneys, shrubs, lawns, patios, pools; lots, parked cars via `staticCarGeo`), trees = clusters of lobes (`oakGeo`/`cedarGeo`, `lite` for the wild woods; `t[3] < .7` = oak) with `leafMaterial` (noise, ragged rim discard, wind sway via `U.uTime`), photo textures from `assets/tex/` (`makeMaterials`, `patchy` breaks up repeats), vehicles (`vehicleGeos`: extruded side profiles + narrower glass `cabin`; looks car/hatch/suv/pickup/van/truck/bus, `LOOK` in game.js maps sim types to looks; `aLight` 1 head / 2 tail / 3-4 left/right blinker, per-instance `aBrake` = brake + 2 * blinker), headlight `beamMaterial`, people (`personGeo` parts + `personMaterial`: limbs swing by per-instance `aWalk`, `aLook` = skin/trousers/hair), lamp models, `buildSignals` (mast arms with a head per lane, lamp list for `drawSignals`; stop signs on plain junctions), `CLOUD` / `cloudUniforms` = drifting cloud shadows (`U.uCloudSh`, `U.uCover`) shared by ground, roads, buildings, roofs, leaves. Weather: `lighting()` picks a cloud cover per day (hash of day + seed, blended) for the sky (`sky.U.uCloud`), cloud shadows and sun strength. Night uses `U.uNight`.
- `game.js`: camera (`cam` target/dist/yaw/pitch), tools (`TOOLS`, `click`, `hoverUpdate`, `previewRoad`, `place`, chain pin `T.pts`, curve pending `T.pend`/`T.bend`, `snapR()` = tap radius from zoom; touch: a quick drag always pans; hold `HOLD` ms then drag draws with Road/Curve (`startDraw`; decided by touch `timeStamp`s at the first real move, the timer only shows the sparkle), two fingers turn/tilt/zoom). `probe` joins any road whose sidewalk the point is on (reach `halfW + 2*WALK_W + 5`), magic sparkles (`burst`), traffic view (`buildOverlay`/`paintOverlay`, one band per edge direction), jam markers, day/night `lighting(hour)` (night is moonlit blue, `dark` = 0.6 of `night`; `nightOn` menu switch; `clockRate` 3x from 21:30 to 5:00), gridlock meter (`simStep`), growth (`growInterval`), saving (`flowtown.save.v1`, every 10 s + pagehide), quality `flowtown.quality` (`QS`), sound (made in code). `window.FT` = test hooks.
- `life.js` (no three): people derived from homes (`pid = building id * 256 + k`, names/age/insurance/tags/temper by hash), jobs (`biz.staff` order = rank: owner, manager, staff; `title`, `boss`, `shift`), routines in `decide` (commute, lunch walk, errands, evening strolls; `go` walks under ~140 m else queues a car trip with `ok`/`fail` callbacks; `carDone` = driver walks kerb to door), visitors (`guests`, through traffic from `exits()` = dead ends outside town), businesses `BIZ` (levels 1-5, `rate`, `spend`, `hours`, `titles`, `pop` gate; till `cash` up to `cashCap`, manager banks from level 3), coins, `COST`, `FINE`, goals, day ledger (`events` 'day'/'goal'). Saves: `life.serialize()` = coins, goals, staff lists; buildings save `biz` as field 18.
- `police.js` (no three): units from stations (`syncUnits`), hiding spots (`findSpots`), radar in `hourly`, `pursue`/`chaseStep` (traffic stop -> ticket, or flee -> arrest/escape), `crash` (cars `hold`+`crashed`, uninsured may flee), `dispatch` to incidents, robberies/carjackings, road rage; `feed` = scanner. net.js car flags: `hold` (stopped in place), `aside` (pulled over: others pass), `siren`/`flee` (through reds), `reckless` (speed, tailgate, may run a red: `ranRed`), `keep` (units: not removed at the destination), `yieldT` (pulling over for a siren). `SVC_TYPES` police/ems/fire via `spawn(..., force)`.
- `scenery.js`: shop name signs (canvas atlas), street trees (passed to buildCity as `opt.more`), poles + wires, hydrants, blades, speed signs, bus shelters, benches, bins, grass/flower clumps. Rebuilt with the city.
- Game flow: boot screen -> title (`titleUp`, orbit camera) -> `play()`; `flowtown.save.v2`; no game over (gridlock just costs income); `onTapWorld` picks coins, people, cars, hidden units, buildings -> `#card` (`.mini` while following: `setFollow`, chase camera in `selTick`, one-finger drag orbits); `law.report(pid)` = lookout (`bolo`), next drive a unit pursues; phone HUD collapses (`#hud.open`); Build tool -> `#pick`; day summary `#daySum` pauses.
- Tests: `node tests/life.mjs`, `node tests/law.mjs`, `node tests/sim.mjs`, `node tests/grow.mjs`, `node tests/build.mjs` (random building stress test incl. lane changes: must report 0 crossings without a junction), `node tests/lanes.mjs` (lane arrows, turn lanes, plain vs widened avenues), `node tests/play.cjs [outdir]`. Run them after any traffic or tool change and report results honestly.

It's an original game in the traffic/city genre: don't copy any existing game's name, art, levels or look.

Screen style (owner): solid road-sign UI (round 2): green guide sign `#hud`, yellow warning sign `#jam`, asphalt dock `#bar` with yellow for the active tile, `.sign` panels (inset border line), Overpass font in `assets/fonts/`. The owner hates the see-through/glassy floating-text look (it reads as AI-made): no translucent panels, text shadows, glows or letter-spaced captions in the UI. Keep it minimal: short labels, no paragraphs on screen, no emoji. Look: semi-realistic aerial view of a Central Texas Hill Country town (real lighting and shadows): 1-2 storey houses with hip roofs, brick/limestone/stucco, driveways and wooden fences; strip centres, big stores, offices and garden apartments on arterials (4 lanes + two-way left-turn lane); a downtown that grows to 3-7 storeys once the town is bigger (owner asked for taller and denser); live oaks and cedars. Don't name the real town in files. Simplified driving.

The owner isn't a programmer: explain changes in plain English and log each round in README.md under History.
